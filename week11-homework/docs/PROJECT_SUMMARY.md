### 5. 运行指南

#### 步骤 1: 安装依赖
```bash
uv sync
```

#### 步骤 2: 配置 API Key
```bash
cp .env.example .env
# 编辑 .env 文件，添加 OPENAI_API_KEY
```

#### 步骤 3: 运行游戏
```bash
# 使用 uv run（推荐）
uv run python -m werewolf.main
```

#### 步骤 4: 查看日志
```bash
ls logs/
cat logs/werewolf_game_*.txt
```

#### 步骤 5: 启动可视化（可选）
```bash
uv run streamlit run werewolf/visualizer.py
```
