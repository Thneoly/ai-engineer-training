## 📖 使用步骤

### 1. 查看历史对局

1. 打开浏览器访问 http://localhost:8501
2. 在左侧选择 "📁 查看历史对局"
3. 从下拉框选择一个对局
4. 查看完整日志或使用搜索功能
5. 可以下载日志文件

**搜索示例：**
- 搜索 "Alpha" 查看某个玩家的所有发言
- 搜索 "投票" 查看所有投票记录
- 搜索 "获胜" 查看游戏结果

### 2. 开始新游戏

#### 方法 A: 通过 Web 界面指导（推荐）

1. 在左侧选择 "🎮 开始新游戏"
2. 查看游戏配置和运行命令
3. 打开新终端窗口
4. 执行命令：
   ```bash
   cd /home/cc/Desktop/code/AIPro/ai-engineer-training/week11-homework
   source .venv/bin/activate
   python -m werewolf.main
   ```
5. 游戏完成后，返回 Web 界面查看记录

#### 方法 B: 直接在终端运行

```bash
# 在项目目录
cd /home/cc/Desktop/code/AIPro/ai-engineer-training/week11-homework

# 激活环境
source .venv/bin/activate

# 运行游戏
python -m werewolf.main
```

## ❓ 常见问题

### Q1: 页面无法加载或显示不完整？

**解决方案：**
1. 使用简化版：`streamlit run werewolf/web_ui_simple.py`
2. 清除浏览器缓存：Ctrl+Shift+R（硬刷新）
3. 检查终端是否有错误信息

### Q2: 历史对局列表为空？

**原因：** 还没有运行过游戏

**解决方案：**
```bash
python -m werewolf.main
```

### Q3: 无法启动新游戏？

**说明：** 当前版本的 Web 界面主要用于查看历史对局。启动新游戏需要在终端运行。

**原因：**
- CrewAI 游戏运行时间较长（3-10分钟）
- 需要实时查看 Agent 对话过程
- 终端模式更适合开发和调试

### Q4: 如何刷新对局列表？

**方法：**
1. 在浏览器中刷新页面（F5）
2. 或者在 Streamlit 界面右上角点击 ⟳ 刷新按钮
